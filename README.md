### Deployment Instructions

1. **Create Project Folder**  
   Create a new folder named `nifty_predictor`. Inside it, create a subfolder named `templates`.

2. **Save Files**  
   - Save the Python code as `app.py` in the root folder.  
   - Save the HTML code as `dashboard.html` inside the `templates` folder.

3. **Run the Server**  
   Open your terminal/command prompt in the root folder and run:  
   ```bash
   python app.py
   ```

4. **View Dashboard**  
   Open your browser and go to `http://127.0.0.1:5000/`.  
   Note: For the most accurate prediction, run this between 8:30 AM and 9:00 AM IST when GIFT Nifty liquidity is highest.
